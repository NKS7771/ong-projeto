# Projeto ONG

Projeto Integrador Extensionista II — Atividade 1.

Projeto desenvolvido para praticar a criação de uma aplicação web com Vite+ e uma API utilizando Node.js e Express.

## Tecnologias

- HTML
- CSS
- JavaScript
- Vite+
- Node.js
- Express

## Requisitos

- Node.js instalado
- npm instalado

## Como executar

### 1. Instalar as dependências

Na pasta do projeto, execute:

```bash
npm install
```

### 2. Iniciar a API

Em um terminal, execute:

```bash
npm run api
```

A API ficará disponível na porta 3000.

### 3. Iniciar o site

Em outro terminal, execute:

```bash
npm run dev
```

Abra o endereço exibido no terminal, normalmente `http://localhost:5173/`.

## Verificar a API

Acesse `http://localhost:5173/api/health` enquanto o site e a API estiverem em execução.

A resposta esperada é:

```json
{
  "status": "ok"
}
```
